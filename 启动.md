
通用：
ros2 run rikibot_base_cpp base_node

ros2 launch rikibot_bringup rikibot_bringup.launch.py

ros2 launch rikibot_lidar rikibot_lidar.launch.py

建图使用：
    ros2 run slam_toolbox async_slam_toolbox_node --ros-args --params-file /opt/ros/humble/share/slam_toolbox/config/mapper_params_online_async.yaml -p base_frame:=base_link

    最后启动控制程序ros2 run teleop_twist_keyboard teleop_twist_keyboard

导航使用：
    # 默认：雷达 + 深度虚拟激光（带三维避障）
    ros2 launch rikibot_nav2 navigation2.launch.py （需要启动相机节点ros2 run rikibot_camera_cpp rikibot_camera_node）
    # 对照基线：纯雷达 
    ros2 launch rikibot_nav2 navigation2.launch.py use_depth_scan:=false

    再在电脑虚拟机ubuntu运行rviz2 -d /opt/ros/humble/share/nav2_bringup/rviz/nav2_default_view.rviz

压缩编码并发布/camera/color/image_raw/compressed和out:=/camera/color/image_raw_uncompressed（用于板卡和主机的wifi链路传输jpeg图像）
ros2 run image_transport republish compressed raw --ros-args -r in/compressed:=/camera/color/image_raw/compressed -r out:=/camera/color/image_raw_uncompressed




补充：ros2 run teleop_twist_keyboard teleop_twist_keyboard --ros-args -p speed:=0.1
